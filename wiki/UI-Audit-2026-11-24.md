# 2026-11-24 · Board 7 bilingual UI audit

[中文](UI-Audit-2026-11-24-zh) · [Individual frames](UI-Gallery) · [Boards and display](Boards-and-Display)

The gallery contains **66 states and 132 host-rendered PNGs** for the 296 × 128 landscape panel. LVGL 9.5.0 runs `WalletUi.cpp`, then `eink_pack_landscape()` converts the pixels to the controller layout. Creation and recovery screens use public fixtures with simulated custody. The production session returns `CustodyUnavailable`.

## Images and interaction

Each language has a 296 × 128, 1 bpp image for each state. The HTML gallery filters by language. The Markdown page links the individual frames and nine overview sheets. [HTML gallery](ui-gallery/index.html) · [Markdown gallery](UI-Gallery)

The BIP39 sequence shows word-list and word-count selection, backup, re-entry, passphrase choice and local confirmation. Bitcoin backup frames show the network, editor, processing, derived address and NFC tag prompt. The gallery also covers home, settings, asset layouts, the companion, receive addresses, transaction review, decisions, pairing and OTP. The receive and review sequences each include scroll positions.

With the display on the left, application keys are OK, Previous, Next and Back. Switch designators SW1/SW2 and the power switch are excluded. Focus uses white text on black. Transaction and pairing pages initially focus the scrollable body. OK selects Reject first; approval requires selecting the other button and separately holding OK for 750 ms. Back rejects. Approval delivery waits for a committed display and each callback is delivered once.

`Language / 语言` on the home menu switches English and Simplified Chinese. The preference lasts until power-off and defaults to English after restart. Active reviews, pairing, OTP and pending decisions prevent switching. Addresses, amounts, fingerprints, memo, calldata, account names and token symbols retain their original content. Only ownership fields explicitly marked as firmware labels are translated; a host account named `EXTERNAL` retains that exact name.

## Findings addressed

| Finding | Change and verification |
| --- | --- |
| English menu content was 14 px high with a 15 px font line | Use 22 px menu buttons and check every button label against its content height. Home shows three complete rows. |
| A fixed buffer could truncate pairing fingerprints | Render the full wrapping fingerprint; cover a 220-character fixture and scrolling. |
| Pairing and serial-code reviews lacked keypad reading focus | Add body focus and scrolling, including access to the final confirmation and seal codes. |
| Repeated or premature approval callback delivery | Deliver once, wait for display commit, and exercise short press, long press, Back and repeated holds. |
| An invalid replacement review could leave an older page visible | Show refusal and revoke old authorization. Excess outputs, truncated formatted fields and entropy failure cannot authorize. |
| Unsupported glyphs, malformed UTF-8 or direction controls could obscure review text | Validate all sealed review strings before enabling authorization. Invalid pairing data is also refused. |
| Asset details and pagination were incomplete | Add scrollable details, wrapping names, page bounds and empty-state focus. Ryo/Zano fixtures follow the release signing gates. |
| Long notices crowded out content; QR failure retained an empty column | Put ordinary long notices in the scrollable body and hide the failed QR column while retaining the full address and path. |
| A display error retained OTP memory | Zero the code and clear display/authorization state. |
| The common signing-review helper silently capped excess outputs | Refuse the complete request instead of displaying a subset. |
| Receive QR codes used too little of the screen | Use the full panel height, four-module quiet zones and integer module sizes; prefer larger modules and refuse single-pixel modules. Full addresses and paths remain scrollable. |
| Asset images shared mutable backing storage | Each canvas owns its draw buffer and releases it on deletion. Tests check distinct images and 16 repeated page rebuilds. Catalog admission checks the icon lookup. |
| Landscape companion actions were unavailable | The home menu opens the companion. Feed, pet, play and blow bubbles use the existing sprite frames. |

UI tests mock display commitment, entropy and review seals. Protocol probes use the real cryptographic implementation with simulated display and approval. These do not prove the physical review-to-signing binding, card execution or side-channel resistance. Users can choose the decision area without a tracked requirement to read every line.

The compiler reported 2,248,800 bytes of program storage and 245,496 bytes of static memory. The internal-memory budget has 82,184 bytes remaining before runtime allocations. Each OTA slot holds 3,932,160 bytes. The last 24 MiB contains `assets`. The ELF links the P4 PIE sprite copy, PPA rotation and the SDK's `dma2d_start`. Runtime counters, independent 2D-DMA use and performance still require board measurements.

## Reproduction

From the repository root, prepare the pinned font source and converter as described in `assets/fonts/README.md`, then run:

```powershell
python tools/generate_ui_font.py --check
powershell -ExecutionPolicy Bypass -File tests/host/ui_check.ps1
python -m pip install Pillow==12.3.0 zxing-cpp==2.3.0
python tests/host/ui/export_panel.py build/ui-test/panel-frames wiki/ui-gallery --markdown wiki/UI-Gallery.md
```

This run used `build/audit-ui` and `build/audit-ui-sanitized`; add `--compare build/audit-ui-sanitized/panel-frames` when exporting the Release frames. Windows clang-cl needs its resource directory's `lib/x86_64-unknown-windows-msvc` available for linking and DLL lookup. Add that directory to `PATH` before CTest. This run used the MSVC developer environment, Ninja Multi-Config and the ASan DLL from that directory.

The UI test logs are `build/audit-ui/Testing/Temporary/LastTest.log` and `build/audit-ui-sanitized/Testing/Temporary/LastTest.log`. The 32 MiB image above came from `build/audit-logs/nfc-backup-p4.log`. With `tests/host/protocol-oracles/node_modules` on `NODE_PATH`, run `node tests/host/key_backup_check.cjs build/audit-native/Release/chain_probe.exe` to reproduce the backup vectors, worker cancellation and allocation-failure checks. The heap probe checks every byte of the scrypt workspace immediately before freeing it. The UI fixtures also complete all five English phrase lengths in both interface languages and exercise locking or losing the display after worker completion.

Documentation checks found the four older requirement screenshots missing from the current workspace. The capability review records their filenames and retains its existing item-by-item analysis. They were not replaced by rendered UI images. The publishing helper now copies the `ui-gallery` attachment directory; publishing was not executed.

## Requirements still outstanding

| Scope | Current status |
| --- | --- |
| Every screen fully bilingual | Landscape menus, backup input and companion actions have both languages. Some protocol details, warnings and portrait text use English. The font covers the offline pinyin dictionary and the bundled Chinese word lists. Account names can contain other characters. |
| Independent creation, recovery and scanning | Four-key BIP39 creation and recovery use simulated custody in host tests. Local Bitcoin backup processing returns a P2PKH address or an encrypted backup. Installing a signing credential in the SE051, NFC enrollment and CSI capture/decoding remain open. |
| SE051C2HQ1 and credential storage | The I²C port passed its host test and compiled for P4. The pinned SDK gates extended PBKDF2 on `SSS_HAVE_SE05X_VER_GTE_07_02`. The installed applet, permissions, non-exportable BIP32 derivation and per-chain signing require card verification. This image's SDK disables Secure Boot, Flash Encryption and NVS Encryption, so `board_credential_storage_ready()` refuses production credentials. |
| Physical operation and performance | COM6 enumerated as an Espressif USB JTAG/serial debug unit (`303A:1001`). A three-second passive read at 115200 baud yielded no complete line. Board identity, key orientation, ghosting, camera, NFC RF, shared-bus timing, current, runtime memory and phone-to-card-to-broadcast operation await measurement. |
| All-chain correctness | 214/214 records address derivation and registration, not complete transaction, card-signing or ledger validation. See the [capability review](Capability-Review). |
