# 威胁模型

[English](Threat-Model) · [首页](Home-zh)

这台设备应当扛住什么、现在扛住了什么、扛不住什么。"状态"一栏描述的是这棵树里的代码，不是打算做什么。

## 对手

| 对手 | 假定的能力 |
| --- | --- |
| 恶意主机或手机 | 完全控制发给设备的每一个字节，可以无限重试 |
| 网络观察者 | 能看到广播后的已签名交易 |
| 小偷 | 拿到设备，没有 PIN，本地时间不受限 |
| 物理攻击者 | 可以拆机、探总线、读 Flash、注入故障 |
| 供应链攻击者 | 可以在刷机前改固件，或替换硬件 |
| 工具链内鬼 | 可以改生成表或某个依赖 |

## 威胁与现状

| # | 威胁 | 状态 | 残余风险 |
| --- | --- | --- | --- |
| 1 | 主机让设备签的东西和用户看到的不是一回事 | 已缓解 | 设备会把重新推导的审查和显示内容逐字段比对；但长得像的地址仍然可能被用户看错 |
| 2 | 主机给的手续费/金额/nonce 自洽但链上是错的 | 部分缓解 | 手续费上限和归属检查能挡住一类滥用，挡不住错误的 UTxO 金额；诱饵、手续费、找零上下文都信任手机 |
| 3 | 重放旧的批准或链路帧 | 已缓解 | 审查封印一次性且会过期；链路帧带单调序号和逐帧 MAC |
| 4 | 未配对手机冒充已配对手机 | 已缓解 | 配对时固定 Ed25519 身份公钥，换公钥直接拒绝 |
| 5 | 小偷暴力破解 PIN | 部分缓解 | PBKDF2-SHA256 12 万轮 + 指数退避。能 dump NVS 的攻击者可以离线全速攻击 verifier |
| 6 | 小偷从 Flash 读出种子 | 当前不在防护范围 | 设备构建根本不存种子；等 SE 托管落地后，种子也不能出现在 MCU Flash 里 |
| 7 | 攻击者替换固件 | 只有开启安全启动 + Flash 加密时才缓解 | 两者默认关闭；`HEXWALLET_REQUIRE_VERIFIED_BOOT=1` 会让签名拒绝，但它不是默认值 |
| 8 | 攻击者读显示总线或 I2C | 未缓解 | 屏幕和 SE 总线没有加密也没有完整性保护；能碰到这些走线，机密性就没了 |
| 9 | 对 MCU 做故障注入（电压/时钟毛刺） | 未缓解 | 没有毛刺检测、没有冗余控制流校验、MCU 也没有相关认证 |
| 10 | 曲线运算的侧信道泄漏 | 部分缓解 | 比较是常量时间的，随机数走 DRBG；但大数运算并非处处常量时间，SE 也还不是签名后端 |
| 11 | 熵源静默失效 | 已缓解 | 连续健康测试；坏块会在本次开机内锁死钱包 |
| 12 | 主机输入触发的解析器内存破坏 | 已收敛，未消除 | 定长缓冲、长度校验、`-W3`/UBSan 构建、无界拷贝的策略检查。但没有 fuzz 框架，也没有形式化验证 |
| 13 | NFC 中继攻击 | 未缓解 | 帧可以被转发；但签名仍需在显示真实收款信息的屏幕上物理按键 |
| 14 | NVS 里的链路身份密钥被攻破 | 部分缓解 | 攻击者可以冒充"设备对手机"；签不了名，因为签名需要 PIN 会话和屏幕 |
| 15 | 恶意供应链（假板、被改过的 SE 固件） | 不在范围 | 固件无法证明硅片是真的 |
| 16 | 胁迫 | 不在范围 | 没有 duress PIN，没有隐藏钱包 |
| 17 | 回滚到旧的已签名固件 | 除非 bootloader 强制防回滚，否则不在范围 | 应用只报告 `running_from_ota_slot`，不阻止降级 |

## 明确不做的事

- **不做节点校验。** 设备不联网，无法知道 UTxO 是否存在、诱饵是否真实、nonce 是否已用、合约是不是它自称的那个。
- **不做多方协议。** 多签、Lightning、Mimblewimble slate 交换、Stacks、门限签名都没实现，它们的威胁模型也就不适用。
- **不做合理否认。** 一个钱包，一个 PIN。
- **没有硬件认证。** 这里没有任何东西通过 FIPS 140-3、CC EAL 或任何智能卡保护轮廓的评估。

## 攻击面清单

| 攻击面 | 入口 | 校验 |
| --- | --- | --- |
| 串口 CLI | `WalletCli.cpp` | 命令缓冲有长度上限，十六进制解码要求精确长度，碰密钥的命令必须先认证 |
| USB APDU | `UsbApduFrame.h`、`WalletNfcApdu.cpp` | ISO 7816-4 分片、最大分片长度、ABORT 清空半成品状态 |
| NFC | `WalletNfcPort.cpp` | NCI 分帧、1 字节长度 + PBF 链式包、不猜引脚 |
| 链路 | `WalletLink.cpp` | 版本字节、精确帧长、先验 HMAC 再解析、序号单调、4096 帧与 3 分钟会话上限 |
| 链解析器 | `*Transaction.cpp` | 逐格式的长度与规范性检查，宁可拒绝也不截断 |
| 安全芯片 | `Se051Apdu.cpp`、`Se051Scp03.cpp` | 改状态之前必须先过 SCP03 认证 |
| Token 元数据 | `WalletCustomTokens.cpp` | 用户自加记录会被标注为"自加"，它们永远不改变被签名的字节 |

## 怎么让这一页变短

按顺序做完下面几件事，上面的表就会缩：

1. SE 托管变成真的：派生和签名走到句柄后面，种子的明文不再存在于 MCU RAM。
2. 安全启动 + Flash 加密成为出货默认，并加上防回滚。
3. CI 里给解析器和链路帧解码器加上 fuzz。
4. 面板和 SE 总线加完整性保护，或者书面接受这个风险。
